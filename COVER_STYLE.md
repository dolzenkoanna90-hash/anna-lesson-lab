# Фирменный стиль обложек «Мастерской Анны Яковлевны»

Референс пользователя: премиальная объёмная 3D-иллюстрация для страницы «ИИ-репетитор. Русский язык — ОГЭ-2027», изумрудная библиотека, кремовая титульная панель с золотой рамкой, мягкий свет, глянцевый белый робот с бирюзовыми глазами, золотые детали, планшет, учебные книги. Исходный визуальный образец предоставлен пользователем 10 ноября 2026 года. Для ОГЭ применять именно этот оригинальный файл, а не похожую генерацию.

## Постоянные признаки
- Глубокий изумрудный: `#073f34`, `#0d5745`; кремовый: `#fffaf0`, `#fff4df`; золото: `#d7af5b`, `#e0bd70`.
- Объёмные 3D-персонажи и предметы, мягкие тени, уютное академическое пространство, библиотеки, книги, тёплый свет, листья и цветы, ощущение качественного современного учебного продукта.
- Золотая рамка и кремовая табличка с названием. Настоящий русский текст размещается HTML/CSS поверх картинки, чтобы исключить ошибки в генерации надписей и сохранить читаемость на мобильных устройствах.
- Образ робота — технологичный, дружелюбный, глянцевый, с бирюзовым экраном лица и золотистыми наушниками. Учителя с планшетом размещать иногда, а не постоянно.
- Каждая обложка показывает конкретный предмет игры: лупа для лексики; зайчик и морковка для Пушкина; фольклорный сундук; перо/газета/микрофон для стилей речи; ворота/дерево/мост/замок для морфемного квеста; ноутбук и карточки для конструктора; робот, учебники и планшет для ОГЭ.
- Изображения сохранять в `assets/covers/`; рабочий формат 16:9. На главной странице — единый `.premium-cover`. Сохранять осмысленные alt-тексты и ссылки на игры.
- Не заменять задания, механику игры или офлайн-доступность ради оформления. Для внутренних страниц можно задавать OG-обложку для предпросмотра в социальных сетях.
